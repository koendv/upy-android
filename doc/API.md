# API reference

Generated by `tools/make-api-md.py` from the `help()` text of each module. Do not edit by hand.

Modules: `camera`, `display`, `android`, `location`, `imu`, `image`, `gif`, `mjpeg`, `crc`, `ulab`, `tflite`, `litert`, `umqtt`, `http`, `zipfile`.

## camera

```
module: camera (CameraX; not OpenMV csi)
functions:
  camera.list(): [{"id": str, "facing": "back"|"front"|"external"|"unknown", "sizes": [(w, h), ...]}, ...]; sizes in sensor orientation (landscape), largest first
class: camera.Camera(id=None, size=(320, 240), format=camera.GRAYSCALE, frame_rate=None)
  id: from camera.list(); None: the first back camera
  size: the listed size with the nearest pixel count is used (orientation of the request does not matter); see size()
  format: camera.GRAYSCALE or camera.RGB565 (CameraX converts to RGB)
  frame_rate: None (automatic; drops in dim light) or (min, max) from supported_frame_rate_ranges(), e.g. (30, 30)
  frames are upright as the phone is held when the camera opens; this does not change while it is open, and the screen locks to it
  front camera images are not mirrored
  one camera open at a time: a new Camera() closes the open one; large sizes need a larger heap (app Settings)
  stays open until close(), a new Camera(), garbage collection or reset, also after the script ends or Interrupt
  with camera.Camera() as cam: ... closes it when the block ends
methods:
  snapshot(): the newest frame not returned before, as image.Image (64-byte aligned); waits for it
  size(): (w, h) of the images snapshot() returns, e.g. (240, 320) for 320x240 held upright
  close(): release the camera
CameraControl methods (CameraX names; each waits until CameraX confirms, at most 5 s):
  enable_torch(on)
  set_torch_strength_level(level): 1..max_torch_strength_level()
  enable_low_light_boost(on)
  set_zoom_ratio(ratio): zoom_state()["min"]..["max"]
  set_linear_zoom(zoom): 0.0..1.0
  set_exposure_compensation_index(index): exposure_state()["min"]..["max"], in steps of ["step"] EV; returns the index set
  start_focus_and_metering(x, y, *, auto_cancel_ms=5000, af=True, ae=True, awb=True): x, y in snapshot coordinates; auto_cancel_ms=0 keeps it; returns True if focus succeeded
  cancel_focus_and_metering()
CameraInfo methods:
  sensor_rotation_degrees(), lens_facing(), intrinsic_zoom_ratio(), implementation_type()
  has_flash_unit(), torch_state(): bool
  is_torch_strength_supported(), max_torch_strength_level(), torch_strength_level()
  zoom_state(): {"ratio", "min", "max", "linear"}
  exposure_state(): {"index", "min", "max", "step", "supported"}
  is_focus_metering_supported(x, y), supported_frame_rate_ranges(): [(min, max), ...]
  is_low_light_boost_supported(), low_light_boost_state(): "off"|"inactive"|"active"
  is_logical_multi_camera_supported()
  not provided (still photos, video, HDR or internal): must_play_shutter_sound, is_zsl_supported, is_private_reprocessing_supported, query_supported_dynamic_ranges, camera_state, physical_camera_infos, is_session_config_supported, camera_selector, camera_identifier
constants: camera.GRAYSCALE, camera.RGB565
errors:
  OSError(EACCES): no camera permission (a prompt is shown; try again after allowing)
  OSError(EIO): camera lost (screen off, app not in foreground, other app) or failed; it is then closed, open a new Camera()
  OSError(ETIMEDOUT): no frame for 2 s (5 s for the first), or a control not confirmed in 5 s
  OSError(ENODEV): control not supported by this camera (no flash unit, ...)
  OSError(EINVAL): method called after the camera was closed (close(), lost, or taken over by a new Camera())
  ValueError: no such camera id, bad size, format or frame_rate, control value out of range
see_also: display.help(), image
```

## display

```
module: display
class: display.SPIDisplay(vflip=False, hmirror=False)
  draws to the app's on-screen camera-preview Surface; the name is carried over from OpenMV's API, there is no real SPI bus involved
methods:
  write(image, x=0, y=0, hint=0): draw an image_t (e.g. from camera.Camera().snapshot()) to the screen
    image must be GRAYSCALE or RGB565, else ValueError; convert with to_grayscale() or to_rgb565()
    image is scaled by the largest power of two (..., 1/4x, 1/2x, 1x, 2x, 4x, 8x) that fits the surface, letterboxed/pillarboxed in opaque black
    hint: OpenMV's IMAGE_HINT_HMIRROR / IMAGE_HINT_VFLIP / IMAGE_HINT_TRANSPOSE bits, combined with the vflip/hmirror set at construction
    no-op (returns None) if no Surface is currently attached, i.e. the app isn't showing the camera screen
see_also: camera.help(), android.help()
```

## android

```
module: android (android-specific, no OpenMV equivalent)
submodules:
  android.proximity: distance_cm() -- proximity sensor reading in cm; OSError(ENODEV) if no sensor
  android.mediastore: save_image(data, name, mime_type="image/jpeg") -- save bytes to the device's shared Photos/gallery; returns the new content:// URI; delete(uri) -- remove an item save_image() returned
  android.fileprovider: share(path, mime_type="application/octet-stream") -- open Android's share sheet for a file; fire-and-forget, no return value, silently does nothing if no app window is focused
functions:
  android.settings() -- dict snapshot of app settings (heap_size_mb, ssh_enabled, adb_exec_enabled); read-only here, set from the app UI
not in this MicroPython: socket, ssl, machine, network, requests, _thread (http does HTTP and HTTPS, umqtt does MQTT)
see_also: camera.help(), display.help(), location.help() (GPS/network location); accelerometer and gyroscope: module imu (OpenMV style: imu.acceleration_mg(), imu.angular_rate_mdps(), imu.roll(), imu.pitch())
```

## location

```
module: location (import location; location.*)
a thin wrapper over Android's LocationManager (GPS/network provider)
methods:
  start(interval_ms=1000, min_distance_m=0): begin location updates
    OSError(EACCES) if location permission not granted (a prompt appears on the phone; run again after granting)
    OSError(ENODEV) if no location provider is enabled in Android settings
  stop(): end updates (also done implicitly by reset())
  read(timeout_ms=0): the fix that's new since the last read() call
    timeout_ms=0: non-blocking, None if nothing new
    timeout_ms>0: wait up to that many ms
    timeout_ms=-1: wait indefinitely (interruptible)
  last(): Android's last known fix regardless of read() history, or None
fix_format: (latitude, longitude, altitude_m, accuracy_m, speed_mps, bearing_deg, time_ms, provider)
  values Android does not have for this fix are None (latitude, longitude, time_ms and provider are always present)
see_also: android.help()
```

## imu

```
module: imu (accelerometer and gyroscope, like OpenMV's imu: functions only, no class)
axes: the phone's own, x to the right, y up the screen, z out of the screen
functions:
  acceleration_mg() -> (x, y, z) in milli-g; (0, 0, 0) if the phone has no accelerometer
  angular_rate_mdps() -> (x, y, z) in milli-degrees per second; (0, 0, 0) if the phone has no gyroscope
  roll() -> degrees, 0 up to 360, from the accelerometer; 0 without one
  pitch() -> degrees, -180 to 180, from the accelerometer; 0 without one
  sleep(enable) -- sleep(True) stops the sampling, sleep(False) starts it again; it starts at the first call
  Each call waits for the next sensor reading.
errors: OSError(ETIMEDOUT) if a sensor gives no reading
see_also: android.help() (proximity sensor), OpenMV's imu module
```

## image

```
module: image (OpenMV's image module)
documentation: https://docs.openmv.io/v5.0.1/library/omv.image.html
  methods and arguments are OpenMV's. This text lists what differs; that page is for v5.0.1, so details can differ.
methods: dir(image.Image); arguments: the documentation above (functions here have no docstrings)
images come from camera.Camera().snapshot(), image.Image(path), image.Image(w, h, format) or image.Image(ndarray)
also available here:
  gamma_corr(), gamma(), awb(), ccm(): awb() and ccm() change RGB565 images only; a grayscale image is left unchanged
  selective_search()
  stereo_disparity(): grayscale image of even width, else ValueError
  ImageIO
  to_ndarray(dtype): dtype 'b', 'B' or 'f'; shape (h, w) for grayscale, (h, w, 3) for RGB565
  image.Image(ndarray): float ndarray of shape (h, w) or (h, w, 3), else ValueError
differences from OpenMV:
  no frame buffer: copy_to_fb=True raises OSError (No free buffers!); leave copy_to_fb out
  ImageIO.read(): copy_to_fb defaults to False (OpenMV: True)
  flush() does nothing
  find_keypoints(): OpenMV's default detector, AGAST, is not included (GPL) and the default returns None; use corner_detector=image.CORNER_FAST
  AprilTag families: image.TAG16H5, TAG25H9, TAG36H10 and TAG36H11 only; the other TAG* constants do not exist
  not provided, they need a ToF or event camera: to_depth(), to_evt_dark(), to_evt_light(), draw_event_histogram(), PALETTE_DEPTH, PALETTE_EVT_DARK, PALETTE_EVT_LIGHT
  csi, sensor, omv and ml do not exist (ImportError): use camera, tflite and litert
haar cascades are in /rom, as in OpenMV: image.HaarCascade("/rom/haarcascade_frontalface.cascade", stages=25), "/rom/haarcascade_eye.cascade" with stages=24
see_also: camera.help(), display.help()
```

## gif

```
module: gif (OpenMV's gif module: write an animated GIF file)
documentation: https://docs.openmv.io/v5.0.1/library/omv.gif.html
  functions and arguments are OpenMV's. This text lists what differs; that page is for v5.0.1, so details can differ.
class: gif.Gif(path, *, width, height, color, loop=True)
  width, height and color left out: taken from the open camera (camera.Camera), else 320x240 grayscale (OpenMV: from the frame buffer)
  color=True: RGB565 frames, color=False: grayscale frames
methods:
  add_frame(image, *, delay=10): delay in units of 10 ms, so 10 is 100 ms; the image must have the width and height of the gif, and not be JPEG or BINARY, else OSError
  width(), height(), format(): image.RGB565 or image.GRAYSCALE, loop(): 1 or 0, size(): bytes written so far
  close(): finish the file
see_also: image.help(), camera.help()
```

## mjpeg

```
module: mjpeg (OpenMV's mjpeg module: write a Motion JPEG video file)
documentation: https://docs.openmv.io/v5.0.1/library/omv.mjpeg.html
  functions and arguments are OpenMV's. This text lists what differs; that page is for v5.0.1, so details can differ.

## crc

```
module: crc (OpenMV's crc module)
functions:
  crc16(data, *, value): CRC-16 with polynomial 0xF94F
  crc32(data, *, value): CRC-32 with polynomial 0xFA567D89
  data: bytes, bytearray or any other buffer, not str; returns an int
  value: the result of the previous call, to continue over more data
  crc16(b'') is 65535 and crc32(b'') is 4294967295
these are not the common CRCs: crc.crc32(b'123456789') is 0x41b403d3, binascii.crc32(b'123456789') is 0xcbf43926
see_also: image.help()
```

```

documentation: https://micropython-ulab.readthedocs.io/en/latest/ (latest version)
  this version: print(ulab.__version__), '<release>-(<dims>)D' or '<release>-(<dims>)D-c'

## tflite

```
module: tflite
class: tflite.Model(path)
  loads a .tflite model and allocates tensors immediately; path is a VFS path (e.g. "/my_model.tflite")
methods:
  run(*inputs): one positional array.array per input tensor, in the model's own order
    strict: each array's typecode and byte size must exactly match the corresponding tensor (no quantization/scale/zero_point handling, no implicit cast)
    returns a single array.array if the model has one output tensor, otherwise a tuple of array.array; always flat (1-D), always a fresh copy
  input_shape(i)/output_shape(i): tuple of dimensions for input/output tensor i; run()'s own arrays carry no shape, query it here
  close(): frees the model and interpreter; also called automatically on garbage collection
functions:
  set_nnapi(enable): True hands models created afterwards to Android NNAPI, False (default) uses the CPU; no argument returns the current setting; reset to False by an interpreter reset
dtypes_supported: float32('f'), int8('b'), uint8('B'), int16('h'), uint16('H'), int32('i'), uint32('I'), int64('q'), uint64('Q'), bool (as uint8 'B', 0/1)
errors:
  OSError(ENOENT): model file not found or not a valid .tflite file
  OSError(EIO): interpreter creation, tensor allocation, inference, or tensor copy failed
  OSError(EINVAL): called on a closed model, a bad tensor index, or a tensor dtype outside dtypes_supported
  ValueError: wrong number of run() arguments, or an input array's typecode/size does not match its tensor
notes:
  NNAPI is deprecated since Android 15 and may silently fall back to the CPU; compare speed to see if it helps (see litert.help() for accelerator-capable inference)
see_also: litert.help()
```

## litert

```
module: litert (standalone LiteRT, not the Play-Store-delivered variant)
classes:
  litert.Environment(): required once per Environment() instance passed to CompiledModel()
  litert.Options(accelerator=litert.Accelerator.CPU, backend=litert.Backend.AUTOMATIC): accelerator is litert.Accelerator.{CPU,GPU,NPU}; NONE exists, but CompiledModel() with it raises OSError(EINVAL)
    backend is litert.Backend.{AUTOMATIC,OPENCL,OPENGL}, for Accelerator.GPU only (else ValueError): AUTOMATIC leaves the choice to LiteRT; OPENCL and OPENGL select one GPU backend; a backend can give wrong results, check them, e.g. /examples/litert_bench.py
  litert.CompiledModel(environment, path, options=None): loads and compiles a .tflite model; path is a VFS path
methods (CompiledModel):
  run(*inputs): one positional array.array per input tensor, in the model's own order
    strict: each array's typecode must be one of f/b/i/q/B (float32/int8/int32/int64/bool); no quantization/scale/zero_point handling, no implicit cast
    returns a single array.array if the model has one output tensor, otherwise a tuple of array.array; always flat (1-D), always a fresh copy
  input_shape(i)/output_shape(i): tuple of dimensions for input/output tensor i; run()'s own arrays carry no shape, query it here
  close(): frees the model; also called automatically on garbage collection
dtypes_supported: float32('f'), int8('b'), int32('i'), int64('q'), bool (as uint8 'B', 0/1) -- the Kotlin litert-api itself has no uint8/int16/uint16 path, unlike tflite
errors:
  OSError(EINVAL): construction with a closed/wrong-type Environment or Options, a CompiledModel() that cannot load or compile the model (for example Backend.OPENCL on a phone without OpenCL), a call on a closed CompiledModel, a bad tensor index, or a dtype outside dtypes_supported
  OSError(EIO): buffer creation, write, run, or read failure (Kotlin/JNI exception text is forwarded)
  ValueError: an unknown backend, or a backend given with an accelerator other than GPU; wrong number of run() arguments, or an input array whose number of elements differs from the tensor's (input_shape(i))
functions:
  version(): "LITERT,MAKER,MODEL", e.g. "2.3.0,QTI,SM8650"; LiteRT version and chip; they select the NPU runtime, see NPU runtime below
accelerators:
  GPU: built in
  NPU: runtimes for MediaTek and Google Tensor are built in; other NPUs need a runtime in /litert/: with Settings > "Load accelerators from /litert/" on and the folder /litert/ present, LiteRT loads the NPU runtime from /litert/ (native code) instead of the built-in runtimes; the setting applies at app start
  NPU runtime, recipe: https://raw.githubusercontent.com/koendv/upy-android/main/doc/NPU.md
  an accelerator that does not load falls back to the CPU without an error; compare run() timing with Accelerator.CPU, e.g. /examples/litert_bench.py
see_also: tflite.help()
```

## umqtt

```
module: umqtt (also importable as umqtt.simple)
class: umqtt.MQTTClient(client_id, server, port=0, user=None, password=None, keepalive=0, ssl=False, ssl_params={})
  MQTT 3.1.1 client with the API of micropython-lib's umqtt.simple
  port=0: 1883, or 8883 with ssl=True
  ssl=True: TLS with Android's CA certificates, host name checked; ssl_params accepts only server_hostname
methods:
  set_callback(f): f(topic, msg) is called with bytes for both
  set_last_will(topic, msg, retain=False, qos=0): call before connect()
  connect(clean_session=True, timeout=None): returns 1 if the broker kept a session, else 0
    timeout in seconds, None: 10 s; Interrupt does not stop a connect, it takes effect after
  publish(topic, msg, retain=False, qos=0)
  subscribe(topic, qos=0), unsubscribe(topic)
  check_msg(): calls the callback for a waiting message, if any; does not wait
  wait_msg(): waits for one message and calls the callback; Interrupt stops the wait
  ping(): OSError ENOTCONN if not connected
  disconnect(): the broker does not publish the last will
  close(): disconnects and frees the client
errors: OSError EIO with the client's message (failed connect, lost connection, timeout)
see_also: /examples/mqtt_tls.py
```

## http

```
http: web requests over okhttp. Every call waits for the result. Not the requests API.
  get(url, timeout=30, headers=None, auth=None)               -> bytes, the response body
  post(url, data, timeout=30, headers=None, auth=None)        -> bytes; data is str (UTF-8, text/plain) or bytes
  put(url, data, timeout=30, headers=None, auth=None)         -> bytes; like post, for WebDAV and similar
  download(url, path, progress=False, timeout=30, headers=None, auth=None) -> None; writes the response body to path
headers: a dict of str to str, e.g. {'Authorization': 'Bearer ' + token}. A 'Content-Type' header replaces
  the default of post and put (application/octet-stream for bytes, text/plain for str). Plain ASCII only,
  else ValueError.
auth: (user, password), HTTP Basic, sent with the first request. Over http:// it is sent in the clear: use https.
  An Authorization header is not sent to another host after a redirect. A 'Authorization' in headers replaces auth.
timeout: seconds, int or float, for connect, read and write. The read timeout is per read, not
  for the whole transfer. 0: no timeout.
redirects are followed, also from http to https. https uses the system's trusted certificates.
  Plain http:// is allowed, for devices on the local network. A 301 or 302 answer to a post or put is
  followed as a get, without the data: use the final https:// URL for uploads.
get, post and put: the whole body must fit in free memory, else MemoryError; use download for large files.
download: path is relative to the files folder, like open(). The body goes to path.part and is
  renamed when complete, so a failed download leaves no partial file. progress=True prints
  percentages (bytes, when the size is not known).
example, a jpeg to WebDAV: http.put('https://host/dav/pic.jpg', jpeg, headers={'Content-Type': 'image/jpeg'},
  auth=('user', 'password'))
example, multipart: boundary = 'xyz'; body = b'--xyz\r\nContent-Disposition: form-data; name="f"; filename="a.jpg"\r\n'
  b'Content-Type: image/jpeg\r\n\r\n' + jpeg + b'\r\n--xyz--\r\n'; headers={'Content-Type': 'multipart/form-data; boundary=xyz'}
errors: OSError. HTTP status 400 or higher: 'HTTP 404' (401 and 403 for a refused login). ETIMEDOUT on a timeout,
  otherwise EIO with the reason. A bad URL, header or content type is a ValueError.
  Interrupt ends the call with KeyboardInterrupt.
limits: no cookies, no response headers or status, no other methods
```

## zipfile

```
zipfile: read and write zip archives. Three functions, not the CPython zipfile API.
  info(zip)         -> [(name, size), ...] in archive order; a folder entry ends in '/'
  read(zip, dest)   -> None; extracts every entry into the folder dest, which is created
  write(zip, path)  -> None; replaces zip with the file or folder tree path
paths: relative to the files folder, like open(); a path that leaves it raises OSError
read: an entry name with a leading '/' or a '..' part is refused and nothing is extracted: on Android 14
  and newer info and read raise OSError (the archive is refused when opened); on older Android info
  lists the names and read raises OSError. A wrong CRC stops read with OSError; entries before it
  stay. Existing files are overwritten.
write: entry names are relative to the parent of path ('data/a.txt' for write(z, 'data')).
  Files only: an empty folder is not stored. The zip itself is skipped. Deflate compression.
errors: OSError, ENOENT for a missing file, otherwise EIO with the reason
limits: cannot be interrupted; no append, no passwords; times, permissions and links are not kept
```
